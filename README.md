# Midnight Bar POS

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร)

## โครงสร้าง
- `index.html` — โครงหน้าเว็บ (HTML เท่านั้น)
- `css/` — สไตล์ แยกตามหน้า โหลดตามลำดับใน index.html (ลำดับมีผลต่อการทับกันของสไตล์ ห้ามสลับ)
- `js/i18n.js` — ระบบสองภาษา ລາວ / English
- `js/logo.js` — โลโก้เริ่มต้น (base64)
- `js/core.js` — ฟังก์ชันช่วย, ค่าตั้งต้น, สิทธิ์, กล่องโต้ตอบ
- `js/auth.js` — เข้าสู่ระบบ/ล็อก, เมนูนำทาง
- `js/menu.js` — ราคา, หน้าเมนู, ตั๋วอໍເດີ
- `js/bill.js` — บิล, แยกบิล, บิลน้อย, ใบสรุปปิดกะ
- `js/payment.js` — ชำระเงิน
- `js/summary.js` — สรุปยอด, ปิดกะ
- `js/bottles.js` — ฝากขวด
- `js/access.js` — หน้าสิทธิ์การใช้งาน
- `js/settings.js` — ตั้งค่าหลังบ้าน
- `js/sheets.js` — ส่งยอดปิดกะเข้า Google Sheets
- `js/main.js` — render หลัก, สลับภาษา
- `js/motion.js`, `js/login-ghost.js` — เอฟเฟกต์

ไฟล์ JS ทุกไฟล์ใช้ตัวแปรร่วมกัน จึงต้องโหลดตามลำดับใน index.html

## ບິນທີ່ບັນທຶກ (Saved bills) — ເພີ່ມໃໝ່
ຮ້ານຍັງບໍ່ມີເຄື່ອງພິມ ລະບົບຈຶ່ງ **ບັນທຶກບິນໄວ້ໃນເຄື່ອງ** ແທນການພິມ.

- ໜ້າ “ບິນທີ່ບັນທຶກ” ໃນແຖບເມນູ: ຊອກຫາ · ກັ່ນຕອງຕາມວັນ/ສະຖານະ · ສົ່ງອອກ CSV
- ບິນຖືກບັນທຶກ 2 ທາງ: ກົດ “ບັນທຶກບິນ” ໃນໜ້າບິນ, ແລະ ບັນທຶກອັດຕະໂນມັດທຸກເທື່ອທີ່ຮັບຊຳລະເງິນ
- ເປີດບິນແຕ່ລະໃບໄດ້: ສຳເນົາເປັນຂໍ້ຄວາມ (ສົ່ງໃຫ້ລູກຄ້າ), ດາວໂຫຼດເປັນໄຟລ໌, ພິມ (ຖ້າມີເຄື່ອງພິມ), ລຶບ (ເຈົ້າຂອງຮ້ານ)
- ເກັບໄວ້ໃນ localStorage (`midnight-bar-pos-saved-v1`) ສູງສຸດ 600 ໃບ ໃບເກົ່າສຸດຈະຖືກຕັດອອກກ່ອນ
- ຖ້າຊື້ເຄື່ອງພິມມາແລ້ວ: ຕັ້ງຄ່າ › ເຄື່ອງພິມ & ໃບຮັບເງິນ › “ເມື່ອປິດບິນ” ປ່ຽນເປັນ “ພິມບິນ”

## ໜ້າຕາ (Theme Holst · Sage & Cream) — ໂທນທີ່ໃຊ້ຢູ່ປັດຈຸບັນ
`css/theme-holst.css` ໂຫຼດທ້າຍສຸດ — ຂຽວເຊຈ #4F7568 ເທິງພື້ນຄຣີມ #F7F0E7 → #CBBEAD,
ຕົວໜັງສືຂຽວເຂັ້ມ #35534A, ການ໌ດ/ແຜງເປັນສີຂາວມຸມໂຄ້ງ, ແທັບໝວດເປັນເມັດຢາ,
ຫົວເລື່ອງ Cormorant Garamond. ໄຟລ໌ນີ້ປ່ຽນແຕ່ສີ/ຄວາມມົນ — ບໍ່ແຕະລະບົບຫຼັງບ້ານ.

ປ່ຽນໂທນ: ແກ້ແຖວສຸດທ້າຍໃນ `<head>` ຂອງ `index.html`
- ໂທນຂຽວເຊຈ (ປັດຈຸບັນ): `<link rel="stylesheet" href="css/theme-holst.css">`
- ກັບໄປໂທນທອງດຳ A2: ປ່ຽນເປັນ `css/theme-a2.css` (ໄຟລ໌ຍັງຢູ່ຄົບ)
- ກັບໄປໂທນເກົ່າສຸດ: ລຶບແຖວນັ້ນອອກເລີຍ

## ປັບປຸງຮອບລ່າສຸດ
- **ຕົວອັກສອນລາວ**: ຫົວຂໍ້ຫຼຸດນ້ຳໜັກມາ 500 ແລະ ເພີ່ມ line-height ເປັນ 1.5 —
  ໄມ້ວັນນະຍຸດທີ່ຊ້ອນກັນ (ເຊັ່ນ ຂໍ້ · ຕັ້ງ · ເຊື່ອ) ຈະບໍ່ຕິດເປັນກ້ອນດຽວອີກ
- **ໜ້າເຂົ້າສູ່ລະບົບ**: ກອບສອງຊັ້ນມຸມມົນ · ເສັ້ນຂີດ+ຈຸດໃຕ້ຊື່ຮ້ານ · ການ໌ດພະນັກງານຢູ່ໃນແຄັບຊູນ ·
  ປຸ່ມ PIN ເປັນວົງມົນ (ປັບຂະໜາດໃຫ້ມືຖືແລ້ວ)
- **ໜ້າເມນູ**: ແຖບຊ້າຍເປັນແຜງຂາວ-ຄຣີມມຸມ 30px · ການ໌ດສິນຄ້າມຸມ 26px ຮູບເປັນໄລ່ສີຂຽວ-ຄຣີມ ·
  ແຜງບິນຂວາຫົວເປັນໄລ່ສີຂຽວອ່ອນ ທ້າຍເປັນຄຣີມ
- **ໃບບິນ**: ປ່ຽນເປັນສີຂາວລ້ວນ + ເງົາຮອບຂອບ + ຮອຍຈັກທາງລຸ່ມແບບໃບບິນຈິງ
- ໜ້າອື່ນໆ (ບິນ ຊຳລະ ບັນທຶກ ສະຫຼຸບ ຝາກຂວດ ສິດ ຕັ້ງຄ່າ) ໃຊ້ໂຄດເດີມ ບໍ່ໄດ້ປ່ຽນໂຄງສ້າງ

## ກົດ "ຄຣີມ = ພື້ນຫຼັງເທົ່ານັ້ນ" (ຮອບ v3)
- ສີຄຣີມໃຊ້ແຕ່ເປັນພື້ນຫຼັງ · ກ່ອງ/ແຜງສະຖານະທຸກອັນເປັນ **ສີຂາວ**
- ບັດທີ່ "ເລືອກ" (ໂຕະ · ສິນຄ້າ · ວິທີຊຳລະ · ພະນັກງານ) = ຂາວ + **ຂອບຂຽວ** (ບໍ່ມີຄຣີມ)
- toggle / pill / segment / ຕົວເລືອກທີ່ active = **ຂຽວເຂັ້ມທຶບ** ຕົວໜັງສືຂາວ
- ໃບບິນ = ສີຂາວ + ເງົາຮອບຂອບ
- ກວດດ້ວຍສະຄຣິບຈັບສີຄຣີມທຸກໜ້າ: ບໍ່ມີກ່ອງສີຄຣີມຕົກຄ້າງ

## ติดตั้งเป็นไอคอนบนหน้าจอ (PWA)
- ไฟล์ที่เกี่ยวข้อง: `manifest.webmanifest` (ชื่อ/สี/ไอคอน), `sw.js` (แคชไฟล์แอปไว้ใช้ออฟไลน์), `icons/` (ไอคอนจากโลโก้)
- ต้องเปิดผ่าน **HTTPS** (หรือ localhost) เท่านั้น — ถ้าเปิดจากไฟล์ตรงๆ ระบบจะไม่ติดตั้ง
- **iPhone/iPad (Safari)**: เปิดลิงก์ → ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
- **Android (Chrome)**: เปิดลิงก์ → เมนู ⋮ → “ติดตั้งแอป” / “เพิ่มไปยังหน้าจอหลัก”
- **คอมพิวเตอร์ (Chrome/Edge)**: กดไอคอนติดตั้งที่แถบที่อยู่
- เมื่อแก้โค้ดแล้วอัปโหลดใหม่: เพิ่มเลขเวอร์ชันใน `sw.js` (`const VERSION = 'mbpos-v2'` …) เพื่อให้เครื่องดึงของใหม่
- ข้อมูลบิล/ยอดขายเก็บในเครื่อง (localStorage) ไม่ถูกลบจากการติดตั้งหรืออัปเดตแอป
